
# Mod-Analyzer

**Mod-Analyzer**, oyun modlarını analiz etmeye ve yapılarını daha kolay incelemeye yardımcı olan bir araçtır. Mod dosyalarını tarayarak içerik, bağımlılık ve olası sorunlar hakkında bilgi sunmayı hedefler.

## Özellikler

- Mod dosyalarını hızlıca analiz etme
- Mod yapısını ve içeriklerini görüntüleme
- Eksik dosya veya uyumsuzluk tespiti
- Kullanıcı dostu arayüz / komut satırı desteği
- Analiz sonuçlarını rapor olarak sunma

## Kurulum

Projeyi klonlayın:

```bash
git clone [https://github.com/CrewManyak/Mod-Analyzer.git](https://github.com/CrewManyak/Mod-Analyzer.git)
cd Mod-Analyzer
```

Gerekli bağımlılıkları yükleyin:

```bash
# Python kullanıyorsanız
pip install -r requirements.txt

# Node.js kullanıyorsanız
npm install
```

## Kullanım

Uygulamayı başlatmak için:

```bash
# Python örneği
python main.py

# Node.js örneği
npm start
```

Analiz etmek istediğiniz mod dosyasını veya klasörünü seçin. Program, modun yapısını tarar ve sonuçları ekranda gösterir.
